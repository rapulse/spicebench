# Workspace Boundary and Installation Rules

## 1. Строгая изоляция рабочей директории (Workspace Boundary)
- Запрещено выходить за пределы корневой папки проекта (`/Users/master/Projects/spicebench`).
- Запрещено читать, создавать, модифицировать или удалять любые файлы и каталоги вне рабочей папки проекта.
- Все команды, утилиты и временные файлы должны быть строго локализованы внутри рабочей директории.

## 2. Запрет на самостоятельную установку сторонних программ и библиотек (Zero Self-Install)
- Агенту категорически запрещено самостоятельно запускать команды установки ПО, системных утилит, brew, npm/pnpm-пакетов, pip-модулей даже внутри рабочей папки.
- Если требуется установить зависимости (например, `pnpm install`, новый npm-пакет или системный бинарник):
  1. Агент обязан сформировать точный список нужных пакетов.
  2. Объяснить пользователю, зачем они нужны.
  3. Вывести в чат точную команду, которую пользователь скопирует и выполнит самостоятельно.
  4. Дождаться сообщения от пользователя об успешном завершении установки перед тем, как продолжать работу.
