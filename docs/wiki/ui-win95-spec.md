# Wiki: Спецификация интерфейса Win95 / EWB 5.12 (`apps/desktop`)

## Визуальный стиль
- Базовая тема: `98.css` (поверхность `#C0C0C0`, рельефные 3D-рамки кнопок, системный шрифт MS 
Sans Serif / Tahoma / fallback sans-serif).
- Монтажное поле: чистый белый фон `#FFFFFF`, дискретная точечная сетка (переключаемая в меню 
View).

## Компоновка главного окна
1. **Menu Bar:** File, Edit, Circuit, Analysis, Window, Help.
2. **Main Toolbar:** стандартные иконки действий (New, Open, Save, Cut/Copy/Paste, Rotate, Zoom) 
+ справа в углу **переключатель питания** (классический тумблер `0 / 1` и кнопка Pause).
3. **Parts Bin Toolbar (вкладки полок компонентов):**
   - `Sources` (земля, батарея, DC/AC источники)
   - `Basic` (резистор, конденсатор, катушка, ключ, потенциометр)
   - `Diodes` / `Transistors` / `Analog ICs` / `Logic Gates` (постепенное наполнение в Фазе 8)
   - `Indicators` (лампа, вольтметр/амперметр, индикатор)
   - `Instruments` (мультиметр, функциональный генератор, осциллограф, плоттер Боде)
4. **Workspace Canvas (SVG):** компоненты со стандартными схематическими символами, цветные 
провода (по умолчанию чёрные, с возможностью смены цвета ветви для каналов осциллографа), 
круглые точки соединений (junction dots).
5. **Status Bar:** координаты курсора по сетке, статус симуляции (`Idle / Running / Error`), 
статус MCP-сервера (`MCP: localhost:7420`).

## Плавающие окна приборов
- Иконка прибора ставится на схему как обычный компонент с клеммами.
- Двойной клик по иконке открывает плавающее окно в стиле Win95 с живыми элементами управления и 
экраном на HTML5 Canvas.
