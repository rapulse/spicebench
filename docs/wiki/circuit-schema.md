# Wiki: JSON-схема цепи (`packages/core`)

## Принципы
- Все координаты (`x`, `y`) — целые числа в единицах логической сетки.
- Углы поворота (`rotation`) — строго `0 | 90 | 180 | 270`.
- Поля номиналов хранят каноническую строку в инженерной нотации (`"10k"`, `"100u"`, `"1M"`, 
`"5"`), парсятся единой утилитой единиц измерения (осторожно: в SPICE `m` = милли $10^{-3}$, а 
мега $10^{6}$ = `meg`).

## Черновой контракт проекта (`.ewb.json`)
```json
{
  "schemaVersion": 1,
  "meta": { "name": "Voltage Divider", "createdAt": "2026-11-18T00:00:00Z" },
  "components": [
    {
      "id": "R1",
      "type": "RESISTOR",
      "label": "R1",
      "params": { "resistance": "10k" },
      "position": { "x": 10, "y": 6 },
      "rotation": 0
    }
  ],
  "wires": [
    {
      "id": "W1",
      "from": { "componentId": "V1", "pinId": "pos" },
      "to": { "componentId": "R1", "pinId": "1" },
      "points": [{ "x": 4, "y": 6 }, { "x": 10, "y": 6 }]
    }
  ],
  "junctions": [{ "id": "J1", "position": { "x": 10, "y": 10 } }],
  "instruments": []
}
```
